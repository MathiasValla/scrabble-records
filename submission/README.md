# Submission files

Upload these files under the corresponding portal categories:

- `manuscript_with_author.pdf`: Manuscript - with author details.
- `manuscript_anonymous.pdf`: Manuscript - anonymous.
- `cover_letter.pdf`: Cover Letter.
- `supplementary_material.pdf`: Supplementary Material for review.

The anonymous manuscript contains no author name, affiliation, local path, PDF
author metadata, acknowledgments, or link to the identifying public repository.
Both manuscript versions contain the same disclosure of generative AI use, as
required by Taylor & Francis policy.
